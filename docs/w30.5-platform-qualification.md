# W30.5 platform qualification

This is an evidence-preserving runbook for the opt-in observability surface. It
does not by itself claim collector reachability, exporter success, or support
for a platform that has not run the commands below.

The scope comes from `WORK_TRACKER.md` § W30.5: qualify macOS, Linux, and
Windows while covering the observability integration without claiming
unverified coverage. The collector boundary comes from
`docs/observability.md` § Verification boundary: deterministic crate tests do
not prove that an external collector is reachable.

## Locked qualification command set

Run from the repository root at the exact revision recorded above. Preserve
stdout, stderr, exit status, and elapsed time in the job artifact.

```sh
cargo fmt --all -- --check
cargo check --workspace --locked
cargo test -p mount-rs-observability --all-features --locked
cargo test -p mount-rs-sdk --features observability --locked
cargo test -p mount-rs-http --features observability-otlp --test http_integration --locked
cargo test -p mount-rs-cli --features observability --locked
cargo check -p mount-rs-napi --features observability --locked
```

The package/feature choices correspond to the declarations in
`crates/mount-rs-observability/Cargo.toml:11-21`,
`crates/mount-rs-sdk/Cargo.toml:11-22`,
`crates/mount-rs-http/Cargo.toml:10-16`,
`crates/mount-rs-cli/Cargo.toml:9-15`, and
`integrations/mount-rs-napi/Cargo.toml:1-11`.

For a qualification run that includes lint evidence, add the matching
feature-gated Clippy commands and retain their complete output. Do not weaken
warnings globally to obtain a pass; document any pre-existing, package-local
lint exception with its source location.
